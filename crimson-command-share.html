Connect a source

Paste a link, name it, and press Test. The check is honest about what it can and cannot do — read the result carefully before trusting a green light.
What "Test" actually does. A saved page cannot read a private Canvas feed — your browser blocks cross-site requests to a domain that has not opted in, and your Canvas feed is authenticated to you. So Test does three real things: it validates the URL structure, it recognises whether the host is one this planner knows how to use, and it attempts a live no-cors reachability probe. A probe can fail on a URL that works fine in your browser, which is why every result tells you which of the three checks passed. For anything the probe cannot confirm, use the paste box below — that path always works.

Screenshot schedule scanner

Drop in a screenshot of your weekly schedule and this reads it with an in-browser OCR engine — nothing is uploaded anywhere, the image never leaves this tab. It looks for a day-header row and an hour axis to work out real times; when it cannot find either, it falls back to mining whatever text it read, same as the Stellic box above.
Click to choose an image, or drag one here.
A clean screenshot of the weekly grid works best — the one you\u2019d get from One.IU\u2019s class schedule view.
What this can and cannot do. The OCR engine (Tesseract.js) loads from a public CDN the first time you scan — that needs internet access, which the hosted preview of this page does not allow; it works when you run the downloaded index.html file yourself. Reading a photo of a screen is harder than a clean screenshot: expect to fix a few rows by hand, and treat every result as unconfirmed until you have checked it, same as everything else this page reads off a picture instead of a real data source. End times specifically run short: a real schedule app draws each class as a colored block, but this only sees the text sitting inside it — a short course name in a long block leaves empty space this can't see, so the guessed end time is often earlier than the real one. Double-check every end time before saving.
